# Support

## How to get help

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/monowar71/Lumen-Media-Server/issues/new?template=bug_report.yml) |
| Feature request | [GitHub Issues](https://github.com/monowar71/Lumen-Media-Server/issues/new?template=feature_request.yml) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private advisory only |
| Contribution questions | Open a Discussion or ask on your PR |

## Before opening an issue

1. Search existing issues for duplicates.
2. Confirm you are on the latest `main` (or a tagged release).
3. Collect logs from the container (`docker logs`) and redact secrets.
4. Note OS, Docker version, hardware accel (`none` / VAAPI / other), and whether the API is LAN-only or reverse-proxied.

## Project status

LumenMedia Server is under active development (pre-1.0). APIs may change; see `openapi.json` and [CHANGELOG.md](CHANGELOG.md).
